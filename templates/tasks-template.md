- No test-first requirement for Build's white-box tests. They may be written during or after implementation.

## Dependencies & Execution Order

- **Setup**: no dependencies.
- **Foundational**: blocks all user stories.
- **User Stories**: depend on Foundational; can run in priority order.
- **Polish**: depends on desired stories.

### Within Each User Story

- Models before services.
- Services before endpoints.
- White-box tests may be written during or after implementation.
- Acceptance verification is external and happens before Build's implementation.

## Implementation Strategy

### MVP First

1. Complete Setup and Foundational.
2. Complete User Story 1.
3. Stop and validate with the frozen acceptance suite.
4. Continue with P2 and P3.

### Incremental Delivery

1. Foundation ready.
2. Add User Story 1 → validate → demo.
3. Add User Story 2 → validate → demo.
4. Add User Story 3 → validate → demo.
